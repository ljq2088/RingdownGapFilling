## 物理量与波形形态

Zhang、Berti、Cardoso，Phys. Rev. D 88, 044018 (2013)，arXiv:1305.4306 的 Fig.1 展示 Schwarzschild 黑洞径向落入问题的 Zerilli 多极波函数。每幅图固定一个角向多极，彩色曲线逐步加入泛音。本文例图展示由源端应变经过 LISA 延迟响应得到的 A/E 分数频率通道。

`verify_waveform_origin.py` 使用原始种子复算并捕获源端极化。两例的干净目标和噪声逐点复现测试数据。主模周期分别为 59.08 s、60.73 s，阻尼时间分别为 60.39 s、62.59 s，每周期约 118、121 个采样点。

当前源端模拟的包络在参考时刻前后分别采用 exp(10t/tau) 与 exp(-t/tau)，连接处连续，两侧一阶导数相差 11A/tau。该结构进入 TDI 延迟组合，产生部分起始折点。该生成约定已经在论文方法中给出。改变起始激发历史需要重新生成数据、评估分布变化并训练或验证相应模型。

采用注入的四个基模频率与阻尼时间，对源端参考时刻后的 h+ 作线性正余弦拟合，相对残差约为 1e-15；对起始过渡后的干净 TDI 片段拟合，相对残差为 1.33e-5 至 5.52e-5。精确窗口及参数见 `waveform_origin_audit.json`。这些拟合用于核查模拟波形的模态内容。论文中的重建曲线直接来自冻结的 DGF 输出。

`source_tdi_diagnostic.png` 单独展示源端极化、TDI 目标、DGF 输出与已知频率的诊断拟合，供技术检查使用；该图未收入论文。
