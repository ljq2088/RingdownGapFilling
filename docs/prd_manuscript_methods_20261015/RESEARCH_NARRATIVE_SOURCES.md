## 结果来源

现阶段主文的 0.00537、幅度残差和相位数据来自 2026-10-08 模型在 1000 个独立受控数值测试源上的完整统计。测试源与训练/验证源分离。该数值波形及噪声的实际离散化完整保留在附录 B。

主文将该最终预测命名为 DGF，删除 Original → First refinement → Augmented 的迭代故事。附录 D 逐项保留三个拟合估计器的原始统计、配对差值、bootstrap 区间和受控消融，说明训练配置差异及其证据范围。主文线性插值对照明确包含缺口外保留的观测噪声。

当前物理 LISA A/E 模型的独立最终测试尚待训练结束。该测试完成后，需要同步绑定同一最终 checkpoint 的方法描述、全体/分层统计、主文所有结果图、摘要和结论。当前版本供作者审阅叙述、方法及图形风格，最终结果来源统一仍为待完成事项。
