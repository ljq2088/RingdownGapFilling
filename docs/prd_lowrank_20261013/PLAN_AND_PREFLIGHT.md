# 全量低秩残差模块训练：计划与前置检查

本轮在旧工作树 `/home/ljq/code/RingdownGapFilling_PRD`、旧分支 `codex/mask-aware-ringdown-optimization` 实施。当前两条GPU长跑继续执行其冻结的代码与评价合同。本轮增加独立的CPU训练流程。

## 模型与人群

保留DGF双分支主干，冻结频率修正长跑第25轮快照，SHA256 `c7069d01d852cfaa5bf33f367d491b76b94ef08ff32f72c56525fa38c53a1774`。训练方向基底来自全部60000个无噪声训练目标，以归一化的联合A/E白化方向构造未中心化协方差，取128维。系数修正头含66688个可训练参数；部署输入为观测、主干预测和已知mask。

源质量1e5–5e6太阳质量，质量比0.3–1，红移1–6，沿用已核验的理想等臂LISA TDI2 A/E合成数据合同。观测为G*h+n，白化前施加信号抑制，缺口内保留噪声。采样2Hz，窗口528秒，缺口33秒。训练、验证、测试保留各自全部样本。

本轮两组都覆盖60000个独立训练源，每源每轮呈现三次，合计180000次。对照组重复原始观测三次；增广组使用原始观测和两份新的独立高斯LISA噪声观测，并对信号与噪声共同施加随机符号。共同符号对应偏振角增加pi/2，保持原来的偏振先验。新噪声由当前物理Simulator.noise生成，先生成与父数据相同的长过程，再按实际源的裁剪位置截取。噪声seed为2146200000–2146319999。每份新观测重新白化并计算旧CWT、低频CWT和db4输入特征。裁剪位置和mask在本轮固定，以隔离噪声增广效应。

## 优化、选择与恢复

- 训练模块从零输出头初始化；4k源筛查的权重与测试流水线检查权重均作为检查产物保留。完整训练采用独立初始化。
- AdamW学习率2e-4、weight_decay1e-4，batch128。均衡损失为直接PSD overlap + 0.5倍相对谱MSE + 0.05倍物理时域/缺口MSE + 0.02倍Hann辅助项。time与Hann项沿用已经核验的物理空间定义。
- EMA衰减0.995。全1500例验证集的直接有符号PSD mismatch算术均值用于选择EMA权重和早停；时间、相位固定。幅度、时域及Hann指标同时报告。
- 最大800轮、最少80轮、patience120、min_delta1e-6。学习率平台patience15，factor0.5，下限2e-6。固定投影初始化纳入最佳权重回退。
- 每轮原子保存模型原始/EMA/最佳权重、优化器、调度器和Torch/shuffle RNG。特征准备按确定的源和噪声seed逐批保存进度。重启 `python -m prd_lowrank.launch` 可恢复缓存准备及训练。
- 两个CPU worker各2线程，使用共享只读memmap；每源端点只保存A/E的DC/Nyquist四个系数。可用RAM低于6GiB时等待。CUDA参与情况为零。

## 独立测试协议

两组完整训练完成后按同一个验证主指标冻结选择，然后生成新的6000例物理测试人群，源seed2034200000–2034205999，噪声seed2134200000–2134205999。该区间与当前训练、验证及另一条长跑预留测试区间独立。测试比较上一轮joint_hann、固定频率修正快照、固定128维投影和两组全量小模块。各模型在相同样本、PSD、窗口和mask下评价，保留全部样本。报告直接 mismatch、时域、Hann、相对L2及成对bootstrap区间。bootstrap描述给定冻结checkpoint条件下的源样本不确定度；训练seed不确定度单独记录。

当前策略筛查的三seed增广验证均值为0.007477162，较固定频率快照0.007866944下降4.955%。完整60000源训练及新独立测试用于验证这条策略的泛化。历史数值目标0.00536876896647继续保留，并与当前物理分布同条件比较分别记录。

## 已完成的前置验证

512份新噪声的有限裁剪periodogram与固定校准PSD的通道中位数比为A=0.995712、E=0.997985；白化标准差通道均值为0.998800与0.997625。重新计算全部输入特征的主干预测与固定缓存预测的相对误差2.58e-7。压缩端点流程复现此前已训练小模块预测的相对误差3.88e-9。继承的原损失复现误差3.73e-9。

128源的三轮训练完成了中断/恢复与连续执行的逐位权重比较，原始、EMA、最佳权重及shuffle RNG一致。最终测试流水线在另外8个检查样本上完成生成、推理、物理PSD评价、独立内积审计及bootstrap输出；这8例用于流水线检查，正式6000例测试保持封存。检查seed2099100000–2099100007，独立于正式人群。

两个并行CPU worker的计算基准各使用2线程，测得每轮180000次呈现的计算时间外推为25.10秒与32.84秒。基准只度量计算开销，权重丢弃；全量缓存访问、验证和checkpoint会增加实际耗时。特征准备的实测小预算吞吐为原始观测约94源/秒，新噪声观测约65–84源/秒。
