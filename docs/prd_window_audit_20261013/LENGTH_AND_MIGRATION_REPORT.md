# 输入长度、最早revise稿与迁移范围核验

结论：当前模型与最早保留的revise稿具有相同的1056点、2Hz输入，即528秒时间窗。差异主要来自缺口时长、物理数据合同、通道和评价指标。保持原DGF双分支和输入布局可以延续同一方法框架；恢复原稿50秒典型缺口及约20%缺口范围，需要新增变长缺口训练与新的独立测试。

## 最早稿件的来源

本轮核对的是原Overleaf项目69bb9d12f9a917663fb9b9c0于2026-10-08首次写作修改前保存的快照：Windows工作区 `outputs/manuscript_writing_20261008/source_before/DGF.tex`。SHA256为 `2750e82cdef8baa1a64e3a11e45dd91aeeb970ee0961358c5b509389314133a0`，与该轮edit_manifest.json的source_sha256一致。项目会话“按审稿意见修订论文”明确记录该稿来自当时侧栏打开的revise版本，随后仅作写作修改。

原稿第259行的pipeline图注给出输入1056点、8个小波通道、32组64点patch、50%重叠；第354行描述典型100点缺口及最高约20%；第435行的波形图注给出2Hz采样。当前模型长度与这些输入设置直接对应。

## 生成父段与训练片段

物理生成器保存的父段为每通道32768点，2Hz对应16384秒，即4小时33分4秒。响应计算还在两侧各增加2048秒padding，内部长度40960点、20480秒。裁剪后训练与评价的输入和目标都是每通道1056点。

528秒片段由已给定的gap位置及固定随机规则确定。当前gap开始位置在片段132–263点，样本的干净ringdown峰值通常位于片段前段；生成时使用已注入信号的峰值安排gap人群，推理输入使用观测和已知mask。父段负责完整生成与裁剪边界，模型评价覆盖声明的528秒片段。

## 冻结模型的缺口时长迁移试验

本轮在已有1500例验证源上固定真实目标、噪声、PSD、时间网格和gap中心，仅改变抑制区间长度。每个新观测重新计算两套CWT和db4特征，使用同一个已冻结主干和noise_augmented第374轮最佳头。原33秒验证均值复现误差为5.558e-10。时间和相位固定，全部1500例保留；这是验证集上的外推诊断。

## 528秒窗口的信号覆盖

父段与验证crop逐例逐位复现。联合A/E时域平方范数的crop/parent比例，均值为98.344%，中位数为99.675%，P10为97.722%。这个量度的是fractional-frequency通道的未加权时域平方范数，PSD加权信息和源辐射能量分别定义。

验证源最长QNM阻尼时间的中位数为174.57秒，P90为820.43秒，最大为1920.32秒。316/1500例（21.07%）的最长tau超过528秒。窗口内峰值之后的可用时间中位数为431.0秒。

因此，当前窗口通常覆盖主要TDI时域幅度结构，较长模态的完整衰减尾部属于更长窗口的评价范围。论文宜将输出定义为“给定528秒分析窗口内的干净ringdown/TDI片段”，并分别讨论模态参数恢复与完整长时序恢复的验证状态。

## 迁移路径

1. 保留原1056点、2Hz、32token的DGF主干布局与波形重建科学问题。当前物理迁移已经使用原主干权重，并通过A/E共享编码、mask/联合残差、低频适配、白化和低秩系数头完成同条件独立评价。新测试中的主模型均值为0.007843351。
2. 对齐原稿缺口范围时，在原长度上加入66–210点的变长gap分布，覆盖100点典型值，重新计算物理观测及全部特征。保留33秒模型和固定基线，并分别报告33、50及约105秒条件。选择完成后用新独立源验证。
3. 数据合同更新为实际的源质量、红移、振幅、有限臂响应、TDI通道、噪声单位和PSD。旧稿SNR1–5/5–10标签、phase统计和旧数值作为历史基准单独记录；新物理人群结果按新SNR定义和直接PSD指标生成相应图表。
4. 更长的分析窗口对应新的长度泛化任务。可研究可变长度序列或重叠窗口的联合重建；基底、PSD、频率网格、时频特征和独立评价随时间合同一起更新。该工作在原稿身份中作为后续扩展定位。
