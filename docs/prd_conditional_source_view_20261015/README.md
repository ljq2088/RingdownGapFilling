# 入射应变的条件重建

本图将既有 DGF 的 A/E 输出投影到与样本源参数一致的 QNM 响应基，再合成进入 LISA 响应之前的入射引力波极化 h+ 和 hcross。该图用于解释与核查，当前 Overleaf 稿件保持此前版本。

固定条件包括注入的探测器参考系质量、自旋、天空位置、倾角、极化角、到达时刻及既有起始包络。采用四个基模的正交相位分量，共八个实线性系数。每个基函数通过原有有限臂长 LISA TDI2 生成器计算。拟合使用同一冻结 PSD 的 A/E 联合加权内积，剔除 DC 和 Nyquist，列归一化后求最小二乘解。合成的光滑度由 QNM 波形族约束提供。

图中蓝线为注入应变，橙色虚线为对 DGF A/E 输出拟合得到的条件应变。时间范围为原始源模型参考时刻后的 0 至 4 tau220；使用 0.5-s 原始采样。该参考时刻沿用稿件的模态振幅定义。源端基函数保留原始预参考历史，但图只展示参考时刻后的衰减段。

三个样本的联合双极化时域相对误差分别为 0.02332、0.03045、0.04623。干净应变经响应后再反演的相对误差小于 2e-15；响应线性叠加误差小于 6e-16。归一化设计矩阵条件数约 6.6--7.4，秩均为 8。

该计算采用已知模拟参数和八维 QNM 约束。参数未知时，需要联合估计参数及重建不确定度。该图刻画这些固定条件下的入射应变恢复；论文原有总体 mismatch 衡量直接 A/E 输出。

对照计算将同一已知响应基经过 G 掩膜后直接拟合原始带噪观测，三个样本的源端误差为 0.03646、0.01126、0.02392。因此，这组三例在固定真实源参数的条件下，直接线性拟合在第二、第三例给出更小源端误差。展示曲线的光滑程度与该强先验有关。模型间总体性能比较沿用论文既有独立测试，条件源端图不提供新的普遍优越性结论。

TDI 延迟将单个源端时刻分布到多个观测时刻，观测域 G 的作用与响应算子一般不交换。源端图使用极化及明确时标；带噪记录、缺口和网络直接输出保留在现有 A/E 图中。
