## SNR约定与数值检查

沿用此前诊断的完整无噪声目标h定义，采用相同的固定有限裁剪PSD、相同的A/E约定和端点规则：

`rho^2 = 4/(fs*N) * sum_AE sum_k=1..N/2-1 |DFT(h)[k]|^2 / PSD[k]`。

这里fs=2Hz、N=1056，DFT为NumPy未归一化FFT，PSD为单侧谱。等价的一侧连续内积为4*delta_f*|delta_t*DFT(h)|^2/PSD的频点和。独立在白化时域利用Parseval关系核验，SNR平方的最大相对差为完整目标8.24e-16、受抑制信号6.18e-16。

每个mismatch继续使用固定时间/相位的有符号联合A/E逆PSD内积，逐源取比值后求算术均值。训练权重和模型选择完全沿用既有冻结记录。

## 不确定度与复现

各阈值报告2000次源样本bootstrap的均值区间及新旧模型成对差区间。该不确定度以固定阈值、校准PSD和checkpoint为条件；完整训练seed的变动由重复训练检验覆盖。阈值列表全部展示，未对模型超参数进行新的选择。

脚本入口：`python -m prd_snr.analyze`。

原始冻结结果：`FillingGap/results_prd_lowrank_20261013/per_example_test.npz`与`fresh_test/truth.npy`、`mask.npy`。诊断输出：`FillingGap/results_prd_snr_conditioning_20261013/snr_conditioned_results.json`、`snr_per_source.npz`。脚本检查6000例seed与预测的对应关系，并逐项复现完整人群的模型均值。
