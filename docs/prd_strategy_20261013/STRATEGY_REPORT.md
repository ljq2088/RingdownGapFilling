## 瓶颈诊断

训练目标的主要逆PSD加权能量集中在约0.005–0.025Hz。此前审计已经确认原高频CWT支路的旧ReLU输出在当前训练/验证人群中为零。当前低频适配器恢复可学习输入通路，已有约0.58%的快照改善。输出残差在0.03–0.1Hz区间占能量约28.1%，目标在该区间占约1.17%；训练方向投影对这类残差提供全窗口约束。

在512个训练样本的预测输出上求梯度，原时域/缺口辅助项的全局梯度范数为主 mismatch 的约10.35倍，Hann辅助项约8.95倍。两者与主项的样本梯度夹角余弦中位数分别约0.189和0.139。时域项样本梯度全部保持非负夹角余弦；这些量刻画输出空间的尺度和方向。共享参数空间的梯度关系需要另行测量。

将时域/缺口权重从0.5降至0.05，Hann权重从0.15降至0.02，在128维小模块中带来较小的额外改善。直接保留overlap与PSD幅度项的试验为0.007502911，Hann指标为0.022141360。因此下一轮保留非零的时域和Hann约束，并记录共享参数梯度尺度。256维增广模块为0.007531885，128维方案在当前筛查中具有更好的主指标。

## 增广的一致性与实现

噪声库两两做正交旋转：`n'_i=cos(theta)n_i+sin(theta)n_j`，`n'_j=-sin(theta)n_i+cos(theta)n_j`。同一系数作用于整个A/E向量。对于独立、零均值、同协方差的高斯样本，这个变换保持联合高斯分布；有限样本库的未中心化二阶矩在变换前后相同。512例检查的最大频点periodogram相对误差为2.69e-15，A/E跨频率二阶矩相对误差为4.05e-16。

共同符号变换同时作用于信号和噪声。信号对应偏振角增加pi/2，噪声保持零均值高斯先验。重新裁剪使用父数据的真实长时序和原有mask生成规则；六个覆盖训练索引范围的样本通过528秒窗口、33秒缺口、物理观测构造和共同符号复现检查。重新裁剪本轮用于一致性测试，训练消融采用固定裁剪。

构造顺序为物理信号与噪声组合、白化、重新计算旧CWT/低频CWT及db4输入特征。白化具有非局域性，因此物理缺口操作在白化前执行。固定红移的振幅改变需要同步更新距离合同；周期移位需要边界合同；独立频点相位变化需要模态相干性合同。当前增广沿用已核验的符号、噪声和裁剪操作。

## 下一轮完整训练规格

1. 固定当前主干快照，使用全部60000个训练源，比较128维固定投影、均衡损失的系数残差头及同更新量的噪声增广头。单轮权重保持逐源均匀，验证保留全部1500例。
2. 每源刷新多份同协方差噪声，重新生成全部输入特征；先隔离噪声增广效果，再增加随机物理裁剪。记录基底秩、能量尾部及各质量/SNR分组的误差。
3. 小模块完整训练采用至少80轮的稳定观察、充分的最大预算和patience120；checkpoint包含模型、优化器、学习率调度器与RNG，按全验证人群直接 mismatch 早停选择。
4. 若小模块完整训练稳定改善，低学习率解冻末端重建模块，并在共同参数空间测量各损失梯度。新增结构继续作为DGF局部扩展。
5. 模型族及选择冻结后生成新6000例独立测试。所有基线在相同PSD、窗口、缺口及测试样本上重新预测，报告直接 mismatch、时域、Hann和幅度误差及成对不确定度。
