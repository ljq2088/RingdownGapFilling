尾部保真度复查与新训练，2026-10-15

当前论文的模型和全部 6000 源统计保持原值。新一轮选择使用 1500 个验证源，最终独立测试种子为 2042200000–2042205999。测试在候选模型与协议冻结后生成。

验证集按各通道真值解析包络在峰值后的振幅比例划分。1%–10% 区间的逐源相对误差中位数为 0.28714，0.1%–1% 区间为 1.18262。后者包含 1002 个具有该区间的验证源。解析相位诊断采用现有 Hilbert 变换约定，其有限窗性质保留在评价定义中。所有源保留在主要 mismatch 统计中。

旧噪声增广长训练在完整 epoch 12 检查点后受控停止。该运行的最佳验证 mismatch 为 0.00791640，来自先导训练的初始候选；完整训练仍保留已有模型。受控停止记录保存在 previous_run_checkpoint_handoff.json。

新候选包括：1121028 参数的系数与端点修正头；646658 参数的多尺度时域 U-Net；1071364 参数的 Kerr 模态阻尼振荡尾部分支。后两者在输出阶段增加现有信号基之外的时域结构。全部候选以现有 DGF 预测为起点，零初始化时逐元素复现起点。

尾部损失覆盖局部振幅与峰值后相位，并以目标信噪可靠度连续加权。主要目标保持直接联合 PSD mismatch。最终候选同时满足每通道峰值相位、高 SNR mismatch、中等振幅尾部相对误差及尾部相位护栏。源参数仅在 QNM 分支的训练辅助损失中使用；推理分支读取观测特征、基线预测、已知掩码及固定预处理。

QNM 容量诊断使用 128 个验证源的真实 remnant 参数和干净拟合片段，在之后的时间片段检验外推。相对误差中位数为 0.000628，对应原模型为 0.420338。该计算描述给定参数和干净片段时的结构表达能力。实际推理结果由训练分支和独立测试决定。

训练保留 60000 个物理源，使用四个观测视图，并增加 10% 的低 SNR 训练观测。每轮 264000 条观测。三组先导各使用 12000 个物理源，每轮 52800 条观测，最少 20、最多 60 个 epoch，patience 20。根据完整验证集选两组进入全量训练，每组最少 80、最多 400 个 epoch，patience 80。优化器、EMA、调度器、随机数和最后完整 epoch 均写入检查点。

数据前向模型继续采用当前孤立 QNM 开启与 TDI 约定。连续并合前史的稳健性检验另行进行。源端偏振图表示模拟输入，当前训练输出仍为 A/E 通道。

模型缓存省去重复的冻结编码器计算，因此 epoch 时长主要反映新分支的有效计算量。训练质量依据完整验证集和冻结后的独立测试判断。论文数字与图件在新结果完成检查后更新。
